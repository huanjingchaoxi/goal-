山特维克（Sandvik Coromant）刀具手册 关键内容摘录
=================================================
（节选，用于知识库检索）

1. 刀具磨损的 7 种主要类型：
   - 后刀面磨损（flank wear, VB）：正常磨损，摩擦导致，可通过降低切削速度缓解
   - 月牙洼磨损（crater wear）：切屑摩擦前刀面形成，受切削温度影响
   - 边界磨损（notch wear）：氧化/加工硬化层导致，出现在切削深度边界
   - 塑性变形（plastic deformation）：刃口热软化，切削温度过高所致
   - 崩刃（chipping）：刃口微崩落，振动、冲击载荷导致
   - 破裂（fracture）：整体断裂，突发性，常见于脆性刀具材料
   - 积屑瘤（built-up edge, BUE）：低速切削时工件材料粘附刃口

2. 后刀面磨损 VB 推荐极限值（mm）：
   - 精加工：VB = 0.2 mm
   - 半精加工：VB = 0.3 mm
   - 粗加工：VB = 0.4 ~ 0.6 mm
   （具体以现场加工要求与工件精度为准）

3. 换刀建议时机：
   - 当 VB 达到 0.3 mm（常规）或工件表面粗糙度变差、出现振纹、加工尺寸超差时换刀
   - 精加工工序建议在 VB = 0.2 mm 前换刀以保证表面质量

4. 故障-信号对应（用于监测）：
   - 振动增大 → 后刀面磨损加剧 / 刀具装夹松动 / 不平衡
   - 切削力上升 → 磨损导致的切削阻力增大
   - 声发射（AE）突变 → 崩刃、涂层脱落、微裂纹
   - 加工表面粗糙度恶化 → 刃口钝化

5. 刀片涂层（CVD/PVD）：涂层磨损完即刃口直接暴露，磨损会加速，需及时换刀。

6. 排屑与冷却：断屑不良会导致积屑瘤与崩刃，冷却不足会加速热磨损。
