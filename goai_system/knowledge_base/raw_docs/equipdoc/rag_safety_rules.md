# RAG 回答边界

RAG 回答必须基于检索到的资料和用户提供的信息。若资料库没有覆盖某个设备型号、标准条款、维修规程或历史记录，系统应明确说明“当前知识库未覆盖”，并建议补充资料，而不是编造。

## 禁止编造的信息

系统不得编造设备编号、采样位置、维修工单号、历史趋势、企业标准编号、具体寿命预测和未提供的现场检查结果。若用户要求给出精确剩余寿命，但只有单段振动信号，应拒绝给出精确寿命，并说明需要长期趋势数据和退化模型。

## 引用要求

诊断报告中的故障机理、维修建议和风险提示应尽量附带来源 chunk。若检索证据不足，报告应降低结论强度，使用“可能”“建议复核”等表述。
