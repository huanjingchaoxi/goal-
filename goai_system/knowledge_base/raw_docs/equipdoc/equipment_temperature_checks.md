# 异常温升排查

设备点检发现温升异常时，应先确认测温位置、传感器安装、环境温度和历史基线，排除测点变化或传感器漂移。单次温度偏高不能直接等同于轴承故障，需要结合升温速率、负载和持续时间判断。

## 机械与润滑因素

机械侧应排查轴承润滑不足或过量、游隙和装配异常、对中不良、摩擦加剧、负载突增以及冷却风道堵塞。同步检查振动、噪声、转速和润滑油状态，可以帮助区分持续摩擦与短时工况变化。

## 电气与冷却因素

电机或电气设备还应检查三相电流是否平衡、接线和接触电阻、绝缘状态、风扇与冷却回路。若温度快速上升并伴随异味、烟雾、异常电流或振动突增，应按现场规程降低风险并安排人工检查，不能仅靠本 Agent 决定是否继续运行。

## 数据补充

建议记录环境温度、测点、负载、电流、转速、振动和连续温度趋势。资料不足时只能给出排查方向，不能编造温升原因、故障等级或停机阈值。
