# 电机常见故障

电机常见故障包括转子不平衡、不对中、轴承损伤、定转子摩擦、绕组绝缘异常和冷却不良。振动信号常用于识别机械类故障，温度、电流和绝缘监测更适合辅助判断电气类问题。

不平衡通常与转频成分增强有关，不对中可能出现转频及倍频成分，轴承故障则可能出现冲击和包络谱特征。若电机温升明显，还需要检查负载、散热、润滑和电气状态。

## 报告建议

若只有振动信号，报告应优先描述机械故障风险，不应直接判断绕组绝缘击穿。若用户询问电气故障但资料库和输入信号不足，应提示需要补充电流、温度或绝缘测试数据。
