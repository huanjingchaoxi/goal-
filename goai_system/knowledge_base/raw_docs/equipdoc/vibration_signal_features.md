# 振动信号分析指标

轴承振动诊断通常结合时域、频域和包络分析。时域指标包括 RMS、峰值、峰峰值、峭度、偏度和峰值因子。RMS 反映整体能量，峭度对冲击较敏感，峰值因子可提示短时冲击，但这些指标都容易受工况和噪声影响。

频域分析通常使用 FFT 观察特征频率及其倍频。包络谱适合识别调制型冲击，尤其在轴承局部故障中常用。若故障激励了结构高频共振，先做带通滤波再进行包络分析可能更清楚。

## 诊断注意事项

单一指标不能作为最终诊断依据。RMS 升高可能来自负载变化、安装松动、共振或故障；峭度升高可能来自冲击故障，也可能来自传感器松动或偶发干扰。频谱峰值也需要结合转速和理论特征频率解释。

实际报告应同时给出结论、证据和限制条件。例如：模型识别为外圈故障，依据包括冲击成分增强和外圈特征频率附近能量升高；但由于只分析单段信号，建议结合历史趋势和现场检查复核。

## 趋势分析

如果要判断故障发展程度，需要连续采样和趋势分析。相比单次诊断，趋势数据能更可靠地区分偶发冲击和持续退化。工程应用中建议记录采样时间、转速、负载、传感器位置和环境信息。
