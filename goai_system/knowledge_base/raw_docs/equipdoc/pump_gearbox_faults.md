# 泵与齿轮箱故障

泵类设备常见问题包括汽蚀（也常写作气蚀）、轴承磨损、不对中、叶轮不平衡和基础松动。汽蚀可能表现为宽带噪声、振动升高、流量或压力波动，并可能伴随类似砂石通过的异常声音。仍需结合入口压力、流量、工况和泵的专用检测信息，不能仅凭轴承分类模型判断。

齿轮箱故障常涉及齿轮啮合频率、边频带、齿面磨损、断齿和轴承问题。齿轮故障诊断需要齿数、转速和传动级信息，否则很难准确解释啮合频率。

## 现场复核建议

怀疑泵汽蚀时，应核对入口条件、阀门状态、流量压力变化和运行声音，并排查叶轮、不对中和基础松动等替代原因。怀疑齿面磨损时，应结合啮合频率及边频带、润滑油磨粒、齿轮参数和拆检信息复核。

## 报告边界

当当前工具只有轴承 CNN 时，系统可以提示泵或齿轮箱可能需要专用工具，不应把所有异常都归因于轴承故障。RAG 的作用是给出诊断边界和下一步数据需求。
