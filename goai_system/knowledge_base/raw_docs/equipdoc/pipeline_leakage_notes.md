# 管道泄漏诊断线索

管道泄漏可能引起声发射、压力波动、局部振动和流量异常。泄漏孔径、压力、介质、管壁材料和环境噪声都会影响信号特征。声发射方法对高频泄漏噪声敏感，但也容易受阀门动作、机械冲击和外界噪声影响。

## 与轴承诊断的区别

管道泄漏不是轴承故障，不能直接使用轴承 CNN 输出结论。若系统尚未接入管道泄漏工具，报告应说明当前工具链只支持轴承 `.npy` 振动信号诊断。RAG 可以提供泄漏诊断思路，但不能伪造工具结果。

## 处理建议

若怀疑泄漏，应结合压力、流量、声发射和人工巡检。对于高风险介质，应优先按安全流程隔离和复核，而不是只依赖单一算法判断。
