# 轴承外圈故障机理

轴承外圈故障通常与外圈滚道局部剥落、点蚀、裂纹或安装座支撑刚度异常有关。当滚动体经过外圈缺陷位置时，会产生周期性冲击，冲击间隔与外圈故障特征频率相关。外圈故障位置相对固定，因此在稳定转速下，振动信号中往往会出现较稳定的冲击重复模式。

外圈故障不应只凭单个频谱峰值判断。工程上通常需要结合时域冲击、频域故障特征频率、包络谱峰值、边频带以及工况信息共同分析。若负载、转速或安装刚度变化明显，故障特征频率附近的能量也会随之变化。

## 振动信号特征

外圈故障常见表现包括：时域信号出现周期性冲击，频域中外圈故障特征频率及其倍频附近能量增强，包络谱中 BPFO 附近峰值更明显。若故障较严重，可能出现宽带冲击能量升高、峭度增大和高频共振带增强。

诊断时需要注意区分外圈故障与安装松动、基础共振、传感器固定不良等问题。松动类问题也可能产生冲击和倍频成分，但通常伴随更明显的低频倍频、非稳定冲击或工况相关性。

## 处理建议

若模型诊断为外圈故障且置信度较高，建议先复核采样点、转速、负载和传感器安装状态，再进行现场检查。维护措施包括检查轴承座配合、润滑状态、外圈滚道磨损、异常温升和噪声。若冲击能量持续升高或伴随温度异常，应安排停机检查或更换轴承。

报告中应明确风险提示：基于单段振动信号的诊断不能替代现场拆检，尤其不能直接推断剩余寿命。若需要寿命预测，还需要长期趋势数据、载荷谱和退化模型。
