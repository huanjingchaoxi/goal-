# 电池热异常监测

动力电池热风险不能由轴承振动 CNN 判断。早期监测通常需要结合单体温度、温升速率、模组内温差、单体电压一致性、电压异常下降、电流、绝缘状态和 BMS 告警，而不是只看一个温度值。

## 多源预警线索

在具备相应传感器时，还可关注异常产气、压力、烟雾或挥发性气体信号，以及冷却系统状态。温度变化、电压异常和气体信号之间的时间关系，比单一阈值更有助于识别风险，但具体阈值必须来自车型、企业规程或经验证的电池系统资料。

## 安全边界

当前知识库不包含特定车型、电芯体系和企业处置阈值，因此不能据此给出可直接执行的热失控判定值，也不能远程控制电池系统。出现快速升温、烟雾、异常气体或 BMS 严重告警时，应遵循现场安全规程并由专业人员处置。
