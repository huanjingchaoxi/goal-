# 维修决策原则

诊断报告应区分“模型结论”和“维修决策”。模型可以根据振动信号给出故障类别和置信度，但是否停机、更换或继续运行，需要结合设备重要性、负载、温度、噪声、历史趋势和生产风险。

高置信度故障并伴随温升、噪声增大或振动趋势恶化时，应优先安排停机检查。若置信度中等或现场症状不明显，建议复测多段信号，确认传感器安装和采样工况，再决定是否拆检。

## 常见处理建议

外圈故障：检查轴承座、外圈配合、润滑状态和滚道损伤。

内圈故障：检查轴与内圈配合、对中状态、轴向载荷和温升。

滚动体故障：检查润滑污染、金属磨屑、冲击载荷和轴承表面损伤。

保持架故障：检查保持架磨损、摩擦噪声、润滑状态和游隙异常。

## 报告边界

报告不应编造设备编号、采样位置、维修工单号或未提供的历史趋势。若输入只包含单段 `.npy` 信号，应明确说明诊断基于单段信号，建议结合现场检查和历史趋势复核。
