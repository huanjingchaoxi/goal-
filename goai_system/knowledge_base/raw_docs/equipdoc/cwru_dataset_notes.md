# CWRU 数据集说明

CWRU 轴承数据集是轴承故障诊断研究中常用的公开数据集，通常包含正常、内圈故障、外圈故障和滚动体故障等类别。数据来自实验台架，常用于验证振动信号诊断模型、特征提取方法和分类算法。

在项目中，CWRU 数据集适合用于验证诊断工具链路：输入一段振动信号，模型输出故障类别、置信度和类别概率。若轻量 CNN 在 CWRU 测试集上达到高准确率，能说明该工具在这个数据集划分下有效，但不能直接等同于真实工业场景泛化能力。

## 局限性

CWRU 数据来自相对标准化的实验条件，真实设备中会有更多干扰，例如转速波动、负载变化、传感器安装差异、背景噪声、复合故障和设备结构差异。因此，CWRU 上的高准确率应表述为“验证诊断工具链路”和“数据集测试结果”，不能夸大为所有真实设备都能达到同样准确率。

若要迁移到真实设备，需要补充现场数据、跨工况测试、域适应、在线校准和长期趋势验证。
