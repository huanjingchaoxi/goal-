# 轴承内圈故障机理

轴承内圈故障常见原因包括内圈滚道剥落、点蚀、裂纹、过盈配合异常和润滑不足。与外圈故障不同，内圈随轴旋转，缺陷进入载荷区时冲击更强，离开载荷区时冲击减弱，因此信号常带有转频调制特征。

内圈故障的诊断应关注内圈故障特征频率 BPFI 及其倍频，也要关注以转频为间隔的边频带。边频带是内圈故障区别于部分外圈故障的重要线索之一。

## 振动信号特征

内圈故障可能表现为周期性冲击、包络谱中 BPFI 及倍频明显、BPFI 两侧出现转频间隔的边频带。若故障发展到中后期，冲击能量、高频共振和时域峭度可能同时升高。

如果只有单个 BPFI 附近峰值，不能直接给出确定结论。应结合转速、负载、采样频率、传感器方向和历史趋势判断。若边频带不明显，也可能与采样长度不足、转速波动或信噪比较低有关。

## 处理建议

高置信度内圈故障建议检查轴承与轴的配合、润滑情况、轴向载荷、对中状态和温升。若存在异常噪声、温度升高或冲击趋势持续恶化，应优先安排停机检查。若只是单次低置信度告警，建议补采多段信号并进行趋势对比。
