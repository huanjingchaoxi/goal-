# 无原始信号时的回答边界

没有采集到原始振动信号时，系统不能执行轴承诊断工具，也不能给出故障类别、类别概率或精确剩余寿命。此时只能依据用户明确提供的现象，给出知识层面的排查方向和需要补充的数据。

## 可以提供的建议

系统可以说明常见故障机理、建议检查的部件、传感器布置与采样要求，并建议记录转速、负载、温度、噪声和历史趋势。用户提供设备类型与现场现象后，也可以列出候选原因，但必须明确这些不是工具诊断结论。

## 不应给出的结论

资料不足时不得声称已经诊断出内圈、外圈或滚动体故障，不得编造现场检查结果、维修工单或采样位置。建议先补采多段原始信号、核对传感器安装，并结合现场点检后再判断。
