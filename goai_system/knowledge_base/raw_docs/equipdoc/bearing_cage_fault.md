# 保持架故障机理

保持架故障包括保持架裂纹、磨损、变形、铆钉松动和润滑不足导致的摩擦异常。保持架转速低于轴转速，因此相关特征常出现在较低频率区域，并可能伴随宽带摩擦噪声。

保持架故障通常不如内外圈故障容易通过单一特征频率稳定识别。实际诊断时需要结合低频调制、冲击、摩擦噪声、温升和拆检信息判断。

## 振动信号特征

保持架故障可能出现 FTF 及其倍频成分、低频调制、非稳定冲击和摩擦引起的宽带能量升高。若保持架破损严重，可能导致滚动体运动受阻，引发更复杂的冲击模式。

如果仅凭短时振动信号，很难稳定区分保持架故障与润滑不足、轻微松动或异物污染。报告中应避免给出过度确定的结论。

## 处理建议

建议检查润滑状态、保持架磨损、轴承游隙和异常摩擦声。若出现温升、噪声加剧或振动突增，应安排停机拆检。若资料不足，应建议补充采样和现场检查，而不是直接推断故障等级。
