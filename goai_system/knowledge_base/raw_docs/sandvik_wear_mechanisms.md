# 山特维克（Sandvik Coromant）官方：切削刃磨损机理

来源: Sandvik Coromant 官方知识页《Wear on cutting edges》
URL: https://www.sandvik.coromant.com/en-us/knowledge/materials/wear-on-cutting-edges
访问日期: 2026-08-08

刀具磨损分为以下主要机理，了解机理有助于判断刀具状态与选择对策。

1) 后刀面磨损（flank wear）——磨粒磨损（abrasive）
最常见的刀具磨损，也是首选的磨损形式，因为其寿命可预测且稳定。后刀面磨损由工件材料中的硬质成分对刀具后刀面的磨蚀引起。

2) 月牙洼磨损（crater wear）——化学磨损（chemical）
发生在刀片前刀面（rake face）上，是工件材料与刀具材料发生化学反应所致，切削速度会放大该反应。过度的月牙洼磨损会削弱切削刃，可能导致断裂。

3) 积屑瘤（built-up edge, BUE）——粘着磨损（adhesive）
切屑在压力下与刀片形成类似压力焊接的粘附，常见于易粘材料（低碳钢、不锈钢、铝合金）。低切削速度会加剧积屑瘤形成。

4) 边界磨损（notch wear）——粘着磨损（adhesive）
表现为切削深度线处前刀面与后刀面同时出现过度局部损伤，由粘着和加工硬化表面引起，常见于不锈钢与耐热合金（HRSA）。

5) 塑性变形（plastic deformation）——热磨损（thermal）
当切削温度对某牌号而言过高时，刀具材料软化发生塑性变形。通常更硬的牌号和更厚的涂层能提高抗塑性变形能力。

6) 热裂纹（thermal cracks）——热磨损（thermal）
切削刃温度快速冷热交替时，产生垂直于切削刃的多条裂纹。常见于断续切削（如铣削），使用冷却液会加剧热裂纹。

7) 崩刃/断裂（edge chipping/breakage）——机械磨损（mechanical）
由机械拉伸应力过载引起，可能的原因包括切屑冲击、切深或进给过大、工件中的砂粒夹杂、积屑瘤、振动或刀片过度磨损。
