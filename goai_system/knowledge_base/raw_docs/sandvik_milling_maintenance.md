# 山特维克（Sandvik Coromant）官方：铣刀维护

来源: Sandvik Coromant 官方知识页《Milling tool maintenance》
URL: https://www.sandvik.coromant.com/en-gb/knowledge/milling/milling-tool-maintenance
访问日期: 2026-08-08

建立车间例行刀具维护制度可提高铣削刀具寿命、预防问题并节省成本。

## 检查刀片座（insert seats）
- 定期检查刀片座，确保加工或搬运中未受损。
- 确保刀片座无污物或加工产生的金属屑。
- 更换磨损或损坏的螺钉与垫圈。

## 扭矩扳手使用要点
- 使用扭矩扳手按每个刀柄推荐扭矩正确锁紧刀片。
- 扭矩过高会负面影响刀具性能，造成刀片、垫圈和螺钉断裂。
- 扭矩过低会导致滑座或刀片移动、振动，并使切削质量下降。
- 建议每年至少一次清洁所有公母配合面并加油润滑；螺纹与螺钉头面按需润滑。
