ISO 3685 《单刃车削刀具寿命试验》 关键条款摘要
================================================
（本文档为 ISO 3685:1993 单刃车削刀具寿命试验标准的关键条款摘要，用于知识库检索）

1. 适用范围：单刃车削刀具（车刀）的寿命试验方法，硬质合金/高速钢刀具的磨损评定。

2. 磨损类型：
   - 后刀面磨损 VB（均匀磨损带宽度，mm）
   - 前刀面月牙洼磨损 KT（深度，mm）与 KM（宽度，mm）
   - 边界/沟槽磨损 VBN、VC（notch wear）

3. 寿命判据（ISO 3685 常用推荐值）：
   - 后刀面均匀磨损：VB = 0.3 mm（硬质合金刀具车削钢件时的常用判据）
   - 后刀面非均匀/边界磨损：VBmax = 0.6 mm
   - 月牙洼磨损：KT = 0.06 + 0.3f（f 为每转进给量 mm/r）；对于硬质合金车刀常取 KT = 0.1 mm 量级
   - 出现崩刃、破裂、刃口剥落等灾难性失效时，立即判为寿命终止

4. 寿命试验需记录：刀具材料、几何角度、工件材料与硬度、切削用量（vc, f, ap）、冷却液、磨损测量间隔。

5. 磨损-寿命曲线（tool-life curve）：lg vc - lg T 成线性关系（Taylor 公式 T·vc^n = C），
   用于外推不同切削速度下的刀具寿命。

6. 与铣削标准的差异：ISO 3685 针对单刃车削，VB 判据与铣削（ISO 8688）接近（0.3 mm），
   但非均匀磨损判据更宽（0.6 mm）。
