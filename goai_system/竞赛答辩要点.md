# GOAI 大赛 · 答辩 PPT 要点

> 面向评委的 8 页演示提纲，每页含核心话术建议。

---

## P1 · 封面
- **项目名**：刀锋智维 —— 面向数控机床刀具磨损的多智能体运维系统
- **一句话定位**：从"异常发现 → 故障诊断 → 维修调度 → 知识沉淀"的完整闭环，让刀具寿命管理从"被动等失效"走向"主动预测+自动决策"

## P2 · 痛点与价值
- **痛点**：刀具磨损突发失效 → 工件报废、机床损坏、产线停机（每台数控机床年损失可达数十万）
- **现有方案局限**：单点监测告警多、误报率高；工程师凭经验、知识难沉淀
- **价值**：预测性维护 → 提前 2~4h 预警换刀；RAG 知识库 → 经验数字化；审批闭环 → 决策可审计

## P3 · 技术架构
- **数据**：PHM2010 铣削公开基准（6 刀 × 315 刀路 × 7 通道信号）
- **特征**：42 维时域特征（振动 RMS、声发射峭度、切削力等）
- **四 Agent**：异常研判 → 故障诊断(RAG) → 维修调度 → 知识沉淀
- **编排**：LangGraph 状态机（含人工审批分支），DeepSeek LLM + 规则双轨兜底

## P4 · 异常发现（Step1-2）
- 磨损三阶段识别（初期/正常/急剧），自动注入 10% 测试误报检验研判 Agent
- **数据支撑**：411 事件、20.2% 触发率、5 类异常；误报过滤率 100%（189/189）

## P5 · 知识库 + RAG（Step3）
- ISO 8688/3685 标准条款 + 刀具厂商手册 + FMEA + 历史案例（109 chunks）
- TF-IDF/FAISS 检索，**幻觉防御**：诊断证据 source 必须来自检索结果
- **数据支撑**：知识库经闭环沉淀 109 → 411 chunks

## P6 · 多智能体闭环（Step4-5）
- **端到端跑通**：411 事件全部处理，151 单诊断、151 工单、45 单需人工审批、151 条知识回写
- 高风险工单自动转人工审批（可审计、可追责）
- **降级设计**：无 API key / 断网时自动切换规则引擎，保证 Demo 可运行

## P7 · 可视化（Step6-7）
- Streamlit 三栏界面：事件流 / Agent 处理过程 / 诊断报告+工单审批
- 审计日志：全节点落盘，SHA256 哈希防篡改，满足工业合规要求

## P8 · 创新点总结
1. **闭环而非单点**：诊断结果自动沉淀回知识库，系统越用越聪明
2. **RAG + 幻觉防御**：证据可溯源，符合工业安全要求
3. **人工审批兜底**：高价值决策保留人因环节，工程落地性强
4. **降级双轨**：LLM 与规则引擎无缝切换，鲁棒性高
5. **数据真实**：基于公开基准数据集，可复现、可量化
